1. 서비스 내용

유튜버 월급명세서(이하 "사이트")는 YouTube 채널의 공개 데이터를 바탕으로 광고 수익을 추정하고 공식 소득 통계와 비교해 보여 주는 무료 서비스입니다.

2. YouTube 서비스 약관 동의

사이트는 YouTube API 서비스를 이용합니다. 사이트를 이용하는 것은 YouTube 서비스 약관에 동의하는 것을 뜻합니다. YouTube가 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

3. 추정치의 한계

  • 사이트가 보여 주는 금액은 공개 데이터와 가정값으로 계산한 추정치이며, 특정 채널의 실제 수익이나 정산 금액이 아닙니다.
  • 추정치를 근거로 한 투자, 계약, 협찬 단가 결정 등으로 생긴 결과에 대해 사이트는 책임지지 않습니다.
  • 추정치를 인용할 때는 "유튜버 월급명세서 추정치"임을 밝혀 실제 수익으로 오해받지 않게 해 주세요.

4. 금지 행위

  • 자동화된 프로그램으로 사이트에 대량으로 요청을 보내는 행위
  • 추정치를 특정 크리에이터의 실제 수익인 것처럼 퍼뜨려 명예를 훼손하는 행위
  • 광고를 반복해서 누르는 등 광고 사업자에게 손해를 주는 행위

5. 서비스 변경과 중단

YouTube API 정책 변경, 사용량 한도, 운영 사정에 따라 사이트 기능이 예고 없이 바뀌거나 일시적으로 중단될 수 있습니다.
