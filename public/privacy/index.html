개인정보처리방침

시행일: 2026년 11월 3일

돈미터(이하 "사이트", https://donmeter.com)는 이용자의 개인정보를 소중히 여기며, 사이트를 이용하는 동안 어떤 정보가 어떻게 처리되는지 아래와 같이 안내합니다.

1. 수집하는 개인정보

사이트는 회원가입이나 로그인 기능이 없으며, 이름, 이메일, 전화번호 같은 개인정보를 입력받거나 저장하지 않습니다.

  • 검색어: 이용자가 입력한 채널 이름, @핸들, 채널 주소는 검색 결과를 가져오기 위해 사이트 서버를 거쳐 YouTube API 서비스로 전송됩니다. 같은 검색의 결과는 응답 속도와 사용량 절약을 위해 최대 24시간 동안 캐시되며, 검색어는 이용자를 식별할 수 있는 정보와 함께 저장되지 않습니다.
  • 회사 비교: 회사 이름은 이용자의 브라우저 안에서 상장사 목록을 찾는 데만 쓰입니다. 회사를 고르면 그 회사의 공시 정보(직원 평균 급여, 평균 근속연수, 임원 보수)를 금융감독원 전자공시 Open API에서 가져오며, 이용자의 실제 근무지나 급여는 묻지도 저장하지도 않습니다.
  • 이용 통계: 사이트 개선을 위해 Google Analytics로 방문 페이지, 고른 색 테마, 검색어, 결과를 확인한 채널 이름, 비교한 회사 이름, "나도 이만큼 벌려면?"에 입력한 구독자 수와 업로드 속도, 대략적인 지역(국가·도시 단위), 기기 종류 같은 이용 통계를 수집합니다. 이 정보는 통계 형태로만 확인하며, 이름이나 연락처처럼 이용자를 직접 식별하는 정보는 수집하지 않습니다.
  • 브라우저 저장소: 같은 채널을 다시 볼 때 빠르게 보여 주기 위해 검색 결과(채널 공개 정보와 최근 영상 조회수)를 이용자의 브라우저 저장소(localStorage)에 최대 24시간 보관합니다. 이용자가 고른 색 테마도 같은 저장소에 기억합니다. 이 정보는 이용자의 기기에만 남으며, 브라우저의 사이트 데이터 삭제 기능으로 언제든 지울 수 있습니다.
  • 접속 기록: 사이트를 호스팅하는 Vercel은 서비스 운영과 보안을 위해 IP 주소, 브라우저 종류, 접속 시간 같은 접속 기록을 처리할 수 있습니다. 자세한 내용은 Vercel 개인정보처리방침을 참고해 주세요.

2. YouTube API 서비스 이용

사이트는 채널 정보와 영상 조회수를 가져오기 위해 YouTube API 서비스를 이용합니다. 이 과정에서 Google이 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다. 사이트를 이용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다.

사이트는 이용자의 YouTube 계정에 접근하지 않으며, 로그인이나 계정 권한을 요청하지 않습니다.

3. 이용 통계(Google Analytics)

사이트는 Google LLC가 제공하는 웹 분석 서비스인 Google Analytics를 사용합니다. Google Analytics는 쿠키를 사용해 이용자가 사이트를 어떻게 이용하는지 분석합니다. 수집된 정보가 처리되는 방식은 Google 파트너 사이트 정보 사용 안내에서 확인할 수 있습니다.

이용 통계 수집을 원하지 않으면 Google 애널리틱스 차단 브라우저 부가기능을 설치하거나 브라우저에서 쿠키를 차단할 수 있습니다.

4. 광고와 쿠키

사이트는 운영비를 마련하기 위해 Google AdSense 광고를 게재합니다.

  • Google을 비롯한 제3자 광고 사업자는 쿠키를 사용해 이용자가 이 사이트나 다른 웹사이트를 방문한 기록을 바탕으로 광고를 게재합니다.
  • Google은 광고 쿠키를 사용해 이용자의 이 사이트 및 인터넷의 다른 사이트 방문 기록을 바탕으로 Google과 파트너가 이용자에게 광고를 게재할 수 있도록 합니다.
  • 이용자는 Google 광고 설정에서 맞춤 광고를 사용하지 않도록 설정할 수 있습니다. 또는 www.aboutads.info에서 일부 제3자 광고 사업자의 맞춤 광고용 쿠키 사용을 거부할 수 있습니다.
  • Google이 파트너 사이트에서 정보를 사용하는 방식은 Google 파트너 사이트 정보 사용 안내에서 확인할 수 있습니다.

카카오톡 공유 버튼을 쓰면 카카오가 제공하는 공유 기능(Kakao SDK)이 동작하며, 이때 처리되는 정보에는 카카오 개인정보처리방침이 적용됩니다.

브라우저 설정에서 쿠키 저장을 거부할 수 있습니다. 쿠키를 거부해도 계산기는 그대로 이용할 수 있으며, 맞춤 광고 대신 일반 광고가 표시될 수 있습니다.

5. 개인정보의 제3자 제공

사이트는 이용자를 직접 식별하는 개인정보를 수집하지 않으므로 제3자에게 제공하지 않습니다. 위에서 안내한 YouTube API 서비스, 금융감독원 전자공시, Google Analytics, Google 광고, 카카오 공유, Vercel 호스팅은 각 회사의 개인정보처리방침에 따라 정보를 처리합니다.
